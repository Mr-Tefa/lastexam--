# FreshCart - متجر إلكتروني متكامل

## 🛒 نظرة عامة

FreshCart هو متجر إلكتروني متكامل مبني بـ React و Tailwind CSS، يوفر تجربة تسوق مميزة للمنتجات الطازجة والعضوية. المشروع يتضمن جميع الميزات الأساسية لمتجر إلكتروني احترافي.

## ✨ الميزات الرئيسية

### 🏠 الصفحة الرئيسية
- عرض المنتجات المميزة والعروض
- عداد تنازلي للعروض المحدودة
- تصفح الفئات والعلامات التجارية
- روابط تفاعلية لجميع الصفحات

### 🔍 البحث والتصفية
- بحث متقدم في المنتجات
- تصفية حسب الفئة والعلامة التجارية والسعر
- ترتيب النتائج بطرق مختلفة
- عرض المنتجات المشابهة

### 🛍️ إدارة المنتجات
- عرض تفاصيل كاملة للمنتجات
- صور متعددة للمنتج مع معاينة
- تقييمات ومراجعات العملاء
- إضافة للسلة والأمنيات

### 🛒 سلة التسوق
- إدارة الكميات
- تطبيق كوبونات الخصم
- حساب الضرائب والشحن
- ملخص الطلب التفصيلي

### ❤️ قائمة الأمنيات
- حفظ المنتجات المفضلة
- إدارة متعددة للمنتجات
- مشاركة قائمة الأمنيات
- إضافة جماعية للسلة

### 👤 نظام المستخدمين
- تسجيل دخول وتسجيل حساب جديد
- نسيان كلمة المرور
- التحقق من البريد الإلكتروني
- إدارة الملف الشخصي

### 📦 إدارة الطلبات
- عرض تاريخ الطلبات
- تتبع حالة الطلب
- تفاصيل الشحن والدفع
- إدارة العناوين

### 💳 نظام الدفع
- خيارات دفع متعددة
- إدخال عنوان الشحن
- تأكيد الطلب
- حماية معلومات الدفع

## 🔗 API Endpoints

المشروع يستخدم API من [E-commerce API](https://ecommerce.routemisr.com/api/v1/):

### المنتجات
- `GET /products` - جلب جميع المنتجات
- `GET /products/:id` - جلب منتج محدد
- `GET /products?keyword=...` - البحث في المنتجات

### المستخدمين
- `POST /auth/signup` - إنشاء حساب جديد
- `POST /auth/signin` - تسجيل الدخول
- `POST /auth/forgotPasswords` - نسيان كلمة المرور

### السلة
- `GET /cart` - جلب محتويات السلة
- `POST /cart` - إضافة منتج للسلة
- `PUT /cart/:id` - تحديث كمية المنتج
- `DELETE /cart/:id` - حذف منتج من السلة

### الأمنيات
- `GET /wishlist` - جلب قائمة الأمنيات
- `POST /wishlist` - إضافة منتج للأمنيات
- `DELETE /wishlist` - حذف منتج من الأمنيات

### الطلبات
- `GET /orders` - جلب طلبات المستخدم
- `POST /orders` - إنشاء طلب جديد
